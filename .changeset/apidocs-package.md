Add `@elide/apidocs`: static HTML and Markdown API reference pages from the `apidocs/1` model that Elide's Javadoc
doclet and Dokka plugin write, with a JSON Schema, a classic-script renderer bundle and runner for JVM tools, client
islands, neutral and Elide theme presets, sample models and a hot-reload development loop.
