Geo measures and draws two-dimensional shapes. This guide is the sample suite for the Markdown importer: each page
exercises some of the Markdown the importer reads. For the classes themselves, read the
[API reference](../api/index.html).

## Sections

- [Getting started](getting-started.md): install Geo and measure a first shape.
- [Concepts](concepts/index.md): shapes, units, callouts and pictures.
- [Advanced topics](concepts/advanced/index.md): what a custom shape must do.
